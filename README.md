# viki-ai

Телеграм бот-компаньон на базе LLM DeepSeek. Сидит в групповом чате (и в личке с владельцем), читает переписку и отвечает как живой участник.

## Что умеет

- отвечает в группах из белого списка, в личке работает только с владельцем
- отвечает, когда её упомянули, ответили на её сообщение или назвали по имени
- сама вклинивается в разговор, а если добавить нечего, молчит
- помнит последние 20 сообщений каждого чата, история хранится в SQLite и переживает перезапуск
- у владельца и остальных разный тон: для каждого ответа случайно выбирается режим (по делу, коротко, с подколкой, сухо, тепло)
- не повторяется: фразы, которые она уже затёрла, подставляются в промпт как запрещённые
- имитирует набор текста: показывает «печатает…» и делает паузу по длине ответа
- может ответить несколькими сообщениями подряд (до 3)
- `/reset` (только для владельца) стирает память чата

## Стек

Python 3.10+, [aiogram 3](https://github.com/aiogram/aiogram), openai SDK (DeepSeek API совместим с ним), aiosqlite, python-dotenv.

## Установка

```bash
git clone https://github.com/unwashide/viki-ai
cd viki-ai
pip install -r requirements.txt
```

## Настройка

**1. Переменные окружения.** Скопируй `.env.example` в `.env` и заполни:

| переменная | что это |
|---|---|
| `TG_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) |
| `DEEPSEEK_KEY` | API-ключ с [platform.deepseek.com](https://platform.deepseek.com) |
| `OWNER_ID` | твой Telegram ID (можно узнать у любого id-бота) |
| `ALLOWED_CHATS` | ID чатов через запятую, где бот может отвечать |

**2. Промпт.** Опиши характер и манеру речи в `prompts/persona.txt`. Сейчас там заглушка.

**3. Имя.** В коде везде стоит заглушка `имя ии`: замени её на имя своего бота в `brain.py` и `memory.py`. Заодно поменяй `DB_PATH` в `config.py`, например на `viki_ai.db`.

**4. Privacy mode.** Чтобы бот видел все сообщения в группе, а не только упоминания, отключи режим приватности: @BotFather → `/setprivacy` → выбрать бота → `Disable`. После этого бота лучше удалить из группы и добавить заново.

## Запуск

```bash
python main.py
```

Запускай из корня репозитория, промпт читается по относительному пути. При старте накопившиеся за время простоя сообщения отбрасываются, так что бот не начнёт отвечать на вчерашний чат.

## Параметры (`config.py`)

| параметр | что делает |
|---|---|
| `LLM_MODEL` | модель DeepSeek |
| `LLM_MAX_TOKENS` | максимальная длина ответа |
| `HISTORY_SIZE` | сколько последних сообщений чата помнит бот |
| `RANDOM_CHANCE` | шанс вклиниться в разговор самой (от 0 до 1) |
| `COOLDOWN` | минимальная пауза между такими репликами, секунды |
| `ONLY_OWNER` | отвечать только владельцу (удобно для тестов) |
| `MAX_INPUT_LEN` | сообщения длиннее обрезаются |

Режимы ответов и минимальный разрыв между репликами (`MIN_GAP`) настраиваются в `brain.py`.

## Структура

```
main.py       запуск и polling
handlers.py   обработка сообщений, задержка набора, /reset
brain.py      когда отвечать, режимы, антиповторы, сборка промпта
llm.py        запросы к DeepSeek
memory.py     история чатов (SQLite + кэш в памяти)
config.py     настройки
prompts/      промпт персонажа
```
